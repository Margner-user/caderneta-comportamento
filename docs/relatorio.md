# Relatório – Caderneta de Comportamento

## 1. Objetivo

Registar e pesquisar alunos e as suas ocorrências, para uso de professores e coordenadores.

## 2. Requisitos

- RF1 Registar aluno (nome, sala, turma, nº emergência, nº encarregado)
- RF2 Pesquisar aluno por nome
- RF3 Registar ocorrências
- RNF1 Dados guardados em ficheiro JSON (sem base de dados)

## 3. Tecnologias

HTML, CSS, JavaScript, Node.js, Git
